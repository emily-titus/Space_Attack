# Space Attack

A space-invaders style game. The player controls a spaceship to fight asteroids that can shoot back.
There are multiple levels that increase in speed and the player only has 3 lives to make it to the end.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Open main.py in vscode
2. run in terminal to set up: py -3.13 -m venv .venv313
   .\.venv313\Scripts\python.exe -m pip install arcade==3.3.3
3. .\.venv313\Scripts\python.exe -c "import arcade; print(arcade.**version**)"
4. To run it: .\.venv313\Scripts\python.exe main.py

Instructions for using the software:

1. Use arrow keys to control player movement
2. Use space bar to shoot
3. Press "R" to restart

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

- vscode
- python 3.13
- arcade 3.3.3
